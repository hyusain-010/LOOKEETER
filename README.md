# LOOKEETER

Lookeeter is an OSINT tool/website that takes an email address input from
the user using it, and searches the web for websites that contains a user
logged in with that email address, a locater that works using email address
basically.
This tool is intended for employers doing background checks of employees,
and finding an co worker or student’s or teacher’s account.
LOOKEETER was inspired by google dorking and is a solution to searching
in each social media for a certain username.
The OSINT tool LOOKEETER is a website, and it works by taking an email
address input from the user, using google dorking commands, and search
the world wide web for such an account with the email address, public
information only, it will output to the user the command it used, so that user
can search by themselves if they want to, after it finishes it will output the
results it has found in the format of links.
The following websites it may be able to find from:
GitHub
Forums
Company websites
Blogs
Public PDFs / resumes
LinkedIn
Social media
Of course, its not guaranteed that it will find exactly what youre looking for,
as the tool works using public information available on the internet, and
isn’t meant for hackers.
For api, progamming language it will use
Programming Language:
 Python
Frontend:
 HTML
 CSS
 JavaScript
Backend Framework:
 Flask
Libraries:
 Requests (for API requests)
 BeautifulSoup4 (for processing web content)
 SQLite3 (for storing search history)
 Email Validator (for validating email input)
Sources and APIs:
 Google Dorking queries
 SerpAPI (to retrieve Google search results)
 GitHub public pages
 LinkedIn public pages
 Public forums and websites
 Have I Been Pwned API (optional, for breach checks)
 Gravatar API (optional, for profile image lookup)
LOOKEETER will only collect and display information that is publicly
available on the internet. It will not attempt to access private accounts,
passwords, or restricted data. The tool will be used for educational
purposes, OSINT investigations, background research, and locating
publicly visible accounts. Search results will not be stored permanently
unless the user chooses to save them, and all searches will comply with
privacy laws and website terms of service. The tool will clearly inform
users that the results may not be accurate or complete and should be
used responsibly and ethically.
